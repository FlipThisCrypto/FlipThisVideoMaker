# Voice preparation

Only clone a voice with documented consent. Record clean mono speech without music or reverb, retain
the original reference, language, style, speed, pitch, provider/model, and consent acknowledgment.
The API rejects reference uploads without consent, and the UI offers deterministic tone preview in
mock mode. Voice-reference audio upload controls are not yet exposed in the UI. External TTS
environments are administrator-installed and never receive credentials in logs.
