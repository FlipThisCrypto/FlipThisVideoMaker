# ADR 0004: License Repository Code Under MIT

## Status

Accepted — 2026-07-12.

## Context

The project is intended to be open source and needs a clear repository code license. Provider code,
model weights, datasets, and generated-output terms remain independent licensing concerns.

## Decision

License original FlipThisVideoMaker repository code under the MIT License, with copyright attributed
to FlipThisCrypto contributors.

## Alternatives

- Apache-2.0: offers an explicit patent grant but adds more compliance text than the initial project
  requires.
- No license: rejected because it would prevent lawful reuse and contribution despite the open-source
  goal.

## Consequences

Contributors and users may reuse the repository code under MIT terms. This decision grants no rights
to external provider code, model weights, datasets, voice references, or generated media.
