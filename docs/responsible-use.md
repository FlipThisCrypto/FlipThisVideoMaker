# Responsible Use

FlipThisVideoMaker is a local production tool, not permission to imitate a person or reuse protected
material. Obtain and record informed consent before using a real person's face, voice, or reference
media. Keep private references and generated assets in the configured data directory; do not commit
or redistribute them without the subject's and rights holder's authorization.

Review every provider's code, model-weight, dataset, commercial-use, and output terms before enabling
it. The optional watermark setting is only a configuration flag today; visible watermark rendering is
not yet implemented, so do not claim outputs are automatically labeled.

The default localhost bind and local authentication mode are the only exercised security boundary.
Do not expose the API publicly without adding and validating authentication, transport security,
access controls, upload limits, and an operational review. Report security issues through
[`SECURITY.md`](../SECURITY.md), not a public issue containing sensitive data.
