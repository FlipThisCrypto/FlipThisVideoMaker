Original FlipThisVideoMaker repository code is licensed under the MIT License. See `LICENSE` and
ADR 0004.

External provider code licenses, model-weight licenses, generated-output terms, voice/reference
consent, and dataset restrictions are separate decisions. Enabling an adapter does not imply that its
models or outputs are licensed for a project.

Before documenting a live provider as implemented, record its upstream project, integration method,
code license, model-weight terms, commercial-use considerations, redistribution rules, and whether
weights are downloaded separately.
